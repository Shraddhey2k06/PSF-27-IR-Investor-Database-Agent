# PSF 2027 Investor Research Hub — FREE GitHub Pages Edition

No OpenAI API key or paid backend is required.

1. Paste Website B.
2. Click **Build Research Queue**.
3. The browser attempts to extract investor names.
4. If CORS/anti-bot blocks the page, paste names manually.
5. Open generated Google/Bing research links.
6. Use ChatGPT Go separately to cross-check public sources.
7. Paste structured JSON into **Import Results**.
8. Export Excel/CSV.

Your ChatGPT Go subscription is not an API credential for a public GitHub Pages site, so this version does not pretend to call your private ChatGPT session. It also does not bypass CORS, anti-bot systems, paywalls, or LinkedIn controls.
